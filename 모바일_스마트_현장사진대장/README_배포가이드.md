# 🐕 뽀삐 [스마트 현장사진대장] 모바일 웹앱 배포 가이드

구글 스프레드시트와 구글 드라이브를 연동하여 현장 스마트폰에서 바로 사진을 찍고 대장에 자동 등록하는 방법입니다.

---

### 1단계: 구글 스프레드시트 열기
1. 구글 드라이브(https://drive.google.com) 접속
2. 새 스프레드시트 생성 (또는 기존 현장관리대장 구글 시트 열기)
3. 상단 메뉴에서 **[확장 프로그램]** → **[Apps Script]** 클릭

---

### 2단계: 코드 2개 복사 & 붙여넣기
1. **`Code.gs` 파일**:
   - Apps Script 편집기 기본 열려 있는 `Code.gs` 안의 내용을 모두 지우고,  
   - 본 폴더의 **`Code.gs`** 파일 내용을 그대로 복사해서 붙여넣습니다.

2. **`index.html` 파일 추가**:
   - 편집기 좌측 파일 목록에서 **[+] (파일 추가)** → **[HTML]** 클릭
   - 파일 이름을 정확히 **`index`** 로 입력 (확장자 .html은 자동 추가됨)
   - 본 폴더의 **`index.html`** 파일 내용을 전체 복사하여 붙여넣습니다.

3. 상단 디스켓 아이콘 **[저장]** 버튼을 누릅니다.

---

### 3단계: 웹앱으로 배포하기 (URL 생성)
1. 편집기 우측 상단의 파란색 **[배포]** 버튼 → **[새 배포]** 클릭
2. 유형 선택 톱니바퀴 ⚙️ 아이콘 → **[웹 앱(Web app)]** 선택
3. 설정값 지정:
   - **설명**: `뽀삐 스마트 현장사진대장 v2`
   - **다음 사용자로 실행**: `나 (My account)`
   - **액세스 권한이 있는 사용자**: `모든 사용자(Anyone)`  
     *(현장 작업자나 폰에서 로그인 번거로움 없이 바로 쓰기 위해 '모든 사용자' 필수)*
4. 하단 **[배포]** 클릭 → 권한 승인 창이 뜨면 **[액세스 승인]** 진행
5. 배포 완료 후 화면에 나오는 **[웹 앱 URL]** 을 복사합니다!

---

### 4단계: 스마트폰에서 사용하기
1. 복사한 웹 앱 URL을 스마트폰 카카오톡이나 문자로 보낸 뒤 폰에서 엽니다.
2. 폰 브라우저 메뉴에서 **"홈 화면에 추가"**를 누르면 스마트폰 앱처럼 아이콘이 생깁니다.
3. 현장에서 **상세위치(예: 101동 301호)** 입력, **공종**, **[진행 / 완료]** 큰 버튼을 터치하고 사진 찍어서 전송하면:
   - 사진 우측 하단에 형광/화이트로 선명한 워터마크가 박히고,
   - 구글 드라이브 사진 보관함에 고화질로 저장되며,
   - 구글 시트와 뽀삐 대시보드에 실시간으로 등록됩니다!
